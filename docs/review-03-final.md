# Review 03: final review of the complete port (Codex gpt-6-astra, high)

The highest-priority issue is that **several conformance runners can report mismatches while `moon test` remains green**. This was a static review; I did not modify files or rerun the suite.

1. **P0 — Make conformance failures fail tests.** [Dialect runner](/Users/hongbozhang/git/sqlglot.mbt/src/dialect_tests/runner_test.mbt:40), base AST/round-trip tests, optimizer fixture/stress runners, lineage, diff, and planner runners accumulate failures and print summaries without asserting success. This does not invalidate your observed zero-mismatch counts, but makes future regressions invisible to exit-status-based CI. Add final assertions, validate fixture tuple lengths, and deliberately corrupt one expected result to verify each harness fails.

2. **P1 — Dialect coverage excludes substantial assertion categories.** [Extraction](/Users/hongbozhang/git/sqlglot.mbt/tools/extract_dialect_tests.py:38) intercepts only three Validator helpers; direct assertions and assertions on returned ASTs are not replayed. Examples without corresponding checks include BigQuery identifier metadata and Snowflake’s `test_type_sensitive_bitshift_transpilation`. Warning assertions also disappear. [Fixture generation](/Users/hongbozhang/git/sqlglot.mbt/tools/gen_dialect_fixtures.py:45) discards recorded errors entirely. Meanwhile, [optimizer error fixtures](/Users/hongbozhang/git/sqlglot.mbt/src/optimizer_tests/harness_test.mbt:94) accept **any** error for an expected error. Port these direct assertions and compare error variants, messages, locations, and warnings. Make extraction fail on unexpected Python test failures and emit a per-test inclusion/exclusion manifest.

3. **P1 — Recording results loses behavioral contracts.** [Diff recording](/Users/hongbozhang/git/sqlglot.mbt/tools/gen_diff_fixtures.py:49) excludes supplied matchings, dialect kwargs, and non-round-tripping ASTs. [Lineage recording](/Users/hongbozhang/git/sqlglot.mbt/tools/gen_lineage_fixtures.py:75) excludes `copy`, callbacks, prebuilt scopes, and `MappingSchema`; textual graph dumps cannot check shared-node identity, once-per-node callbacks, or unique DAG traversal. Optimizer schema-cache assertions are missing, and the [UNNEST memoization test](/Users/hongbozhang/git/sqlglot.mbt/src/optimizer_tests/qualify_unit_test.mbt:608) checks only termination. Add direct identity, mutation, callback-order, and operation-count tests. Separately inventory intentional omissions: dynamic expression subclasses, Python import/plugin machinery, metadata-consistency introspection, external integration loading, and executor DuckDB comparisons.

4. **P1 — AST fixtures normalize away representation differences.** [Python canonicalization](/Users/hongbozhang/git/sqlglot.mbt/tools/gen_fixtures.py:55) drops `None` list members, `None` arguments, and empty lists, and omits metadata/parent links. [Value conversion](/Users/hongbozhang/git/sqlglot.mbt/src/core/expr.mbt:84) likewise drops missing list elements; the corresponding expression-equality assertion is explicitly skipped. `Expr::has` correctly implements **truthiness**, so it must not replace key membership or `is not None`. Add a matrix covering missing, explicit None, false, zero, empty string/list, and SQL NULL through construction, mutation, equality, and serde. Either represent these distinctions explicitly or document the narrower contract.

5. **P1 — Fluent builders silently change Python’s copying contract.** [Builder methods](/Users/hongbozhang/git/sqlglot.mbt/src/core/builders_query.mbt:1) explicitly default to `copy=false`, whereas Python defaults to copying. Thus deriving two queries from one base can mutate both references. Chained SQL-output tests barely exercise this. Add branch-from-one-base tests, including child parent/index integrity. Restore Python defaults or prominently document mutation and provide clearly named copying/in-place alternatives.

6. **P2 — Unicode and regex compatibility remains partial.** Tokenization and `substr` already use code points; a blanket UTF-16 diagnosis would be inaccurate. However, [core case conversion](/Users/hongbozhang/git/sqlglot.mbt/src/core/helper.mbt:5) uses incomplete one-character mappings: `ß → SS`, dotted İ, contextual Greek sigma, and supplementary letters need checks. [ILIKE matching](/Users/hongbozhang/git/sqlglot.mbt/src/executor/env.mbt:333) approximates Python regex case-insensitivity through those mappings. Differentially test identifier normalization, ILIKE, astral-character positions/slicing, and Unicode character classes; use complete Unicode tables.

7. **P2 — Numeric and ordering boundaries need targeted tests.** Optimizer [numeric folding](/Users/hongbozhang/git/sqlglot.mbt/src/optimizer/pynum.mbt:13) already uses BigInt, but AST values, host `PyInt`, and executor integers remain Int64. [Serde loading](/Users/hongbozhang/git/sqlglot.mbt/src/core/serde.mbt:65) falls back to Double conversion when integer parsing fails. Test ±2⁶³ boundaries, overflow arithmetic, shifts, huge literals, and serde round trips; reject unsupported values explicitly. Ordering is also deliberately normalized in diff/lineage/planner fixtures, while executor [set emulation](/Users/hongbozhang/git/sqlglot.mbt/src/executor/pyset.mbt:1) substitutes insertion order for randomized hashes. Check ordering only where observable and promised, across insertion orders and Python hash seeds.

8. **P2 — Benchmark adversarial shapes, not just fixture sizes.** [Simplifier deduplication](/Users/hongbozhang/git/sqlglot.mbt/src/optimizer/simplify.mbt:471) uses linear structural searches; `flat_simplify` adds pairwise scans and front-array removal. [Parser substring extraction](/Users/hongbozhang/git/sqlglot.mbt/src/core/helper.mbt:422) converts the entire string on every call. Parenthesis/unary generation remains recursive and repeatedly concatenates growing strings, despite iterative binary generation and AST copying. Benchmark doubling sizes for wide predicates, repeated hints, nested parentheses/functions, and shared CTEs; track allocations/RSS across backends. Use indexed deduplication, cached source characters, and depth/work budgets.

9. **P2 — Make the facade independently usable.** [Public signatures](/Users/hongbozhang/git/sqlglot.mbt/src/pkg.generated.mbti) expose core types without re-exporting them. [Builders](/Users/hongbozhang/git/sqlglot.mbt/src/builders.mbt:30) require homogeneous generic arrays or explicit Python-object adapters for mixed inputs. Re-export principal types/errors, provide documented mixed-expression examples, and compile examples importing only the facade. Also expose parser limits through `transpile`, and replace string-valued identify/normalization modes with enums.
